# Video Checklist

Before recording:
- [ ] Camera enabled
- [ ] Face visible throughout
- [ ] Application screen visible
- [ ] Microphone tested
- [ ] Notifications disabled
- [ ] Browser tabs closed except required ones
- [ ] API key not visible
- [ ] Terminal does not show secrets
- [ ] Application already running

Demo order:
1. Introduction
2. Problem understanding
3. Architecture
4. Tech stack
5. Interview Guide
6. Themes & differences
7. Ask across transcripts
8. Evidence explorer
9. Hallucination prevention
10. Scaling
11. AI disclosure
12. Closing

Target duration: 5–10 minutes.
Recommended: ~7–8 minutes.

After recording:
- [ ] MP4 is <= 1 GB OR upload to Drive/WorkDrive
- [ ] Link access tested in incognito
- [ ] GitHub repository opens
- [ ] README opens
- [ ] Repository contains no `.env`
- [ ] Final demo matches submitted code
